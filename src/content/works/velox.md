## The Problem

Tuning Windows usually means jumping between a lot of places. Some settings sit deep in menus, some need a registry change or a script, and cleaning up the system or freeing memory needs yet another tool. It's easy to change something and then forget how to put it back.

## The Solution

Velox puts all of that in one desktop app for Windows 10 and 11. I built it so you can apply a tweak with one click and undo it just as easily, make a restore point before you change things, and see how your PC is doing on a live Performance page.

It ships with Velox Mem (VeloxMem), a small memory cleaner that lives above the tray. You turn it on from Velox, and it can boost your memory with one click, clean temp files and show a live memory graph. Velox is free and open source under the GPL-3.0 license.

## What it does

- 43 Windows tweaks, each one can be applied and undone
- Debloat, a system cleaner and restore points
- Windows Update control, a DNS manager and an app installer
- A live Performance page for CPU, memory, GPU and per-app usage
- Velox Mem: one-click Boost, Extreme clean, temp-file clean, auto-clean and a memory graph
